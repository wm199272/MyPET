# MyPET

一本只属于你和它的档案。体重、洗澡、驱虫、疫苗、体检、口粮和开销都记在手机里，不用登录，也不上传。

## 能做什么

- **档案**：记下名字、生日、性别、绝育和品种。猫狗可以从常见品种里选，也可以拍一张照片让它认。
- **立体形象**：按品种放一只可以转动的形象。上传胸背、四脚衣或凉凉衣的照片，能试穿上看看。
- **口粮**：选择主流品牌，记下这一袋的规格。按包装上的用量估算每天吃多少、大概哪天吃完，并在快吃完或快过期时提醒。
- **驱虫、疫苗、体检、洗澡、体重**：按你填的日期记录。驱虫可以选常见品牌，也可以自己写。
- **记账**：食物开支可以和登记的口粮连在一起，首页会一起提醒。花费可以按分类和月份查看。
- **提醒**：食品保质期和口粮吃完，提前 7 天和当天各提醒一次；驱虫、疫苗和体检，提前 3 天和当天各提醒一次。
- **算一卦**：用生日或摇铜钱，给它看一眼今天的运气。

用量和驱虫间隔都来自包装说明，不是兽医建议。它不判断生不生病，也不推荐药品。
